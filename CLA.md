## 8. How to agree

When you open a pull request, tick the box in the pull request description that says:

> I have read the [Contributor License Agreement](CLA.md) and agree to it for this and my
> future contributions to Nearside.

If you contribute in another way, for example a patch in an issue, write that sentence in
the same issue or message.

Agreeing once covers all your later contributions to Nearside under this version of the
agreement.
