# Code of conduct

Nearside follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, welcome people of every background and level
of experience, and keep discussions about the work. Harassment, insults, and publishing
anyone's private information are not tolerated, in issues, pull requests or anywhere else the
project lives.

## Reporting

If something happens that isn't OK, report it privately to the maintainer through
[GitHub](https://github.com/ramiejleh) or by opening a
[private security advisory](https://github.com/ramiejleh/Nearside/security/advisories/new)
if it can't wait. Reports are kept confidential.

The maintainer may remove, edit or reject comments, commits, code and issues that don't follow
this code, and may block people who repeatedly or seriously break it, as described in the
Covenant's enforcement guidelines.
